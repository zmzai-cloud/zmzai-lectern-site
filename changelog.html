v0.17.0

2026-10-24 Release ↗ 最新

消息流真流式 + 更新器断点续传

  • 升级内置框架引擎（0.17.2 → 0.18.0）：模型回复从「攒一大段一次性蹦出」变为逐字流出。
  • 长回复的中间快照写入降频，会话重放更快，事件日志不再随回复长度膨胀。
  • 更新包下载支持断点续传与失败自动重试，弱网环境升级更稳。
  • 下载源故障时自动回退镜像；安装失败时给出可诊断的错误信息。

v0.16.0

2026-10-21 Release ↗

更新日志与应用内重启确认

  • 账户区更新图标支持悬停查看版本、发布日期与分组改动，下载前就知道这一版改了什么。
  • 下载完成后在应用内选择「稍后」或「重启以更新」，不再弹系统确认框。
  • 任务运行中仍可查看日志，但重启按钮禁用并说明原因，避免中止正在跑的任务。
  • 发布日志随更新清单下发；旧客户端忽略该字段，更新清单格式保持兼容。

v0.15.1

2026-10-19 Release ↗

更新安装链路修复

  • 修复 macOS 替换旧应用时定位错一层目录导致安装失败的问题。
  • 手动重启与退出自动安装不再各拉起一次替换脚本，只执行一次。
  • 检测到新版本时账户区直接显示更新图标，下载与就绪状态一眼可见。
  • 替换保留旧版备份，新版启动成功后自动清理；下载残留同样自动清理。

v0.15.0

2026-10-18 Release ↗

应用内自动升级

  • 启动检查到新版本后在后台静默下载，不打扰正在运行的任务。
  • 下载完成后正常退出应用即自动安装，下次打开就是新版。
  • 替换前解压并核验更新包，保留一份旧版作回滚；校验失败不动现有应用。
  • 设置 → 通用可关闭自动更新，关闭后仍可从账户菜单手动检查。

v0.14.2

2026-10-17 Release ↗

消息流三处减法

  • 任务已交付时不再叠加「本轮已结束」摘要卡，结论只出现一次。
  • 项目记忆引用行移到最新一条用户消息前——召回属于那一轮任务，不是会话全局状态。
  • 收起的工作流程行显示真实工具概览（如「读取 3 · 编辑 2 · 执行 · 42s」）。

v0.14.1

2026-10-16 Release ↗

项目记忆安全与可靠性修复

  • 记忆凭据绑定服务端用户身份；退出或切换账户清理本地凭据与运行缓存。
  • 单条记忆详情严格检查知识库可见权限，创建不会认领无归属的上游库。
  • retain 失败不再伪装成功；并发同键不重复发起写，状态不明进入显式对账。
  • outbox 原子领取；旧候选不会跨知识库重发，迟到回执不覆盖已失效记录。

v0.14.0

2026-10-13 Release ↗

项目记忆（K1）

  • 登录自动接通 memory.zmzai.cloud，桌面端凭据后台签发与轮换。
  • 每个项目跑第一个任务时自动创建专属知识库并绑定，零操作。
  • 新任务把项目约定、有效命令、架构决策与故障结论作为背景注入，来源可展开。
  • 交付后提炼 ≤5 条知识候选默认待审，可改写后采纳；写入策略可切换。
  • 本地 outbox 幂等重试、状态不明先对账；可换绑包括 Agent 工作区在内的知识库。

v0.13.0

2026-10-12 Release ↗

交互全流程走查修复

  • 运行中可排队发送：发送保持主位，中止退为次要描边，不再互相顶掉。
  • 乐观气泡先半透明、落地转实；中断未确认时发送键指向恢复横幅。
  • 交付后的结论段加一档字号与字重，过场叙述与最终答案一眼可分。
  • 删除会话改用应用内确认框，破坏性操作单独分隔并常态标红。
  • 搜索结果展示命中数，运行状态行改用中文短语。

v0.12.1

2026-10-09 Release ↗

恢复横幅在桌面模式复活

  • 修复任务中断后被挡时桌面版只显示一行英文码 RECOVERY_REQUIRED 的问题。
  • Host 错误体对齐契约，前端识码双通道兜底；「核对并继续上次任务」横幅稳定出现。

v0.12.0

2026-10-09 Release ↗

会话流改版 + 子代理消息盒

  • 过程行弱化为「图标 中文名 · 摘要」，思考行显示持续时长，失败才整行标红。
  • 一轮结束后过程收拢成「工作流程 · N 个步骤 · 时长」，正文留在原位。
  • 运行中断的错误收成一行「运行中断 · 一句话原因」，展开才看原始错误。
  • 工作台新增「子代理」标签页，只读渲染子会话转录并自动跟随运行中的子代理。
  • 点击发送瞬间清空输入框、气泡同帧上屏；失败完整恢复已输入内容。

v0.11.0

2026-10-08 Release ↗

生产链路收口（R0）
