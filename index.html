0.10 · 本版三件新武器

Agent 说「做完了」，凭什么信？

这一版把「交付」拆成三道关卡：任务在隔离工作区里干，成果过真浏览器验证，干不了的桌面操作由它请求、你放行——每一道都有证据落盘，不是一句口头「完成」。

1Isolation

任务隔离工作区

git worktree · per task

每个任务使用独立工作区，修改时不影响你的主工作区。你审阅后再合并，也可以放弃这次修改。

  • 合并前检查分支是否有新改动，有变化就暂停，避免覆盖他人的工作
  • 合并冲突会保留现场与问题清单，解决后可以重试
  • 记录每一步合并进度，中断后可继续，避免重复操作
  • 审阅后代码再次变化，会提示你重新检查
2Verification

真浏览器验证

built-in chromium · evidence

验收不是「模型说测试过了」——应用内置的 Chromium 真的把页面跑一遍，断言过了才算交付。

  • 必须通过设定的功能检查，仅页面能打开或有截图还不够
  • 分别记录桌面和手机的检查结果，方便定位问题
  • 保留浏览器报错、资源加载失败记录和现场截图
  • 验证后你改了一行代码，旧证据即作废；首败自动修复一次，二次停手
3Computer Use

桌面控制

macos · accessibility

原生应用、系统对话框这种没有 API 的界面，agent 走 macOS 辅助功能结构化操作——点的是按钮本身，不是截图猜坐标。

  • 动作前观察、动作后核对效果；观察 5 秒过期，陈旧点击直接拒绝
  • 全桌面同一时刻只有一个控制者，排队不抢你的键盘鼠标
  • ⌘⇧⌫ 一键紧急停止，排队中的动作全部作废
  • 密码、验证码永远由你输入；每次动作脱敏记入交付证据

Foundation

新武器脚下的底座。

三道关卡之下，是长期打磨的工作台基本面：执行过程全程可见、断线可续、会话可回卷、每次写盘与命令都有审计。每一项到底怎么用，见 功能说明。

01
会话回卷rewind · truncate-from
会话底部的时间轴可拖回任意一轮之前，消息树在该点截断、agent 从那里重新出发。截断走事件溯源并下发 rewound 事件，被切掉的消息不会在重连重放时复活。
02
断点续传sse resume · reconnect
事件流带序号，断线后从断点重放，配指数退避重连。弱网、休眠唤醒、代理切换都不再整页刷新重来。
03
增量投影o(1) per event
事件流增量折叠成消息树，替代旧的全量重投影。几千条消息的会话照样流畅滚动，触顶自动分页加载历史。
04
Diff 审阅shiki highlight
右侧看板实时呈现本轮触碰的文件与变更，Shiki 按语言按需加载高亮，明暗主题跟随系统。
05
命令与搜索cmd-K · cmd-P · cmd-Shift-F
三模式命令面板：执行命令、跳转会话、全文搜索历史。键盘优先，和引擎对话不离开键盘。
06
权限审计audit.db
每一次文件写入与命令执行都落独立审计库，manual / auto / fine-grained 三种来源分开记账，失败不阻塞主流程。
07
托盘常驻menubar · darwin
菜单栏显示运行状态——运行中、等待授权一目了然；任务完成发系统通知，人不在屏幕前也不错过。

Workflow

三步，一个本地循环。

没有云端排队，没有浏览器标签页——任务从下达到落地，全程跑在你自己的机器上。

你
重构客户端的重连逻辑，跑通测试后提交。

01
下达任务prompt · natural language

用一句话交代要做什么，就像跟同事说话。要改哪个文件、跑什么命令、按什么标准收尾，一次说清。

bash · pnpm test client

02
授权执行read · edit · bash · authorize

Agent 读文件、改代码、跑命令、看结果，迭代推进。需要权限的动作会停下来问你，而不是擅自执行。

03
审阅落地diff · commit

每一处改动都呈现在右侧看板，带语法高亮。确认后由你决定提交——机器不替你拍板。
