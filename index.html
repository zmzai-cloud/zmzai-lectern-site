01

派任务

一句话交代目标，Agent 在独立工作区里读代码、改文件、跑测试；复杂任务可派只读子代理并行探索。

worktree · subagents 02

diff · rewind · audit 03

GitHub 仓库 Release Notes

Apple Silicon 选 .dmg；Intel Mac 暂不支持；Windows 10 1809 以下请升级。校验下载包：shasum -a 256 文件名（Windows 可用 certutil -hashfile 文件名 SHA256）。

macOS 包未做开发者签名与公证，Windows 包未做代码签名，首次打开可能被系统拦截；处理方式见常见问题。更新后会话与设置保留。
