0.11 · R0 生产链路收口

单兵能干，生产链扛事。

这一版把三件地基打进产品：agent 能派子代理并行干活、所有命令经独立 Host 执行且崩了可查可续、合并前对合并结果真跑验证——每一环失败都显式、可恢复、有证据。

1Subagents

子代理生产链路

agent_spawn · park · verify

Agent 可以派出多个只读子代理并行探索，自己继续推进主线；子代理收尾后父任务自动等候、验收、汇总——不需要你催「继续」。

  • 子代理失败绝不伪装成完成——失败原因进记录，父任务看得见才决定补救
  • 多项目共享全局额度（全局 6 / 每任务 3）；任务树之外的操作一律拒绝
  • 应用重启后：排队中的子任务自动恢复执行，中断的进入恢复审查，不重放未知副作用
  • 派生幂等：同一次派生重试只会拿到同一个子代理，不会重复执行
2Host Reliability

Host 命令可靠性

single executor · receipt

所有命令经独立 Host 进程执行，与界面服务隔离。Host 出问题时明确报「结果未知」——绝不静默换一条路重跑，杜绝同一命令被执行两次。

  • 每条命令可查回执：同一 requestId 重试只会拿回原结果，不会二次执行
  • 多项目会话按持久归属路由；重复会话、缺失挂载按错误处理，不静默串库
  • 启动即对账：重启后遗留任务立即结算，首屏看到的就是恢复后的真实状态
  • 模式在启动时锁定：Host 故障不会悄悄退回进程内执行掩盖问题
3Merge Verification

合并结果实检

verify the merge · not the parts

合并前对实际合并出的代码执行验证计划（比如真跑一遍测试）——两边测试各自通过、组合到一起挂掉时，你的分支一动不动。

  • 验证证据绑定 merge commit + 内容指纹 + 计划版本；源码再变，旧证据一眼判失效
  • 整合中断后恢复：重新验证放行，不凭旧证据免检，也不重复合并
  • 验证集由仓库声明（.lectern/verification.json）；没有计划时按显式「接受未验证」放行并如实标注
  • 整合期间别人推进了目标分支 → CAS 拒绝并保留现场，不覆盖任何人的工作

Foundation

新武器脚下的底座。

生产链之下，是长期打磨的工作台基本面：执行过程全程可见、断线可续、会话可回卷、每次写盘与命令都有审计。每一项到底怎么用，见 功能说明。

01
会话回卷rewind · truncate-from
会话底部的时间轴可拖回任意一轮之前，消息树在该点截断、agent 从那里重新出发。截断走事件溯源并下发 rewound 事件，被切掉的消息不会在重连重放时复活。
02
断点续传sse resume · reconnect
事件流带序号，断线后从断点重放，配指数退避重连。弱网、休眠唤醒、代理切换都不再整页刷新重来。
03
增量投影o(1) per event
事件流增量折叠成消息树，替代旧的全量重投影。几千条消息的会话照样流畅滚动，触顶自动分页加载历史。
04
Diff 审阅shiki highlight
右侧看板实时呈现本轮触碰的文件与变更，Shiki 按语言按需加载高亮，明暗主题跟随系统。
05
命令与搜索cmd-K · cmd-P · cmd-Shift-F
三模式命令面板：执行命令、跳转会话、全文搜索历史。键盘优先，和引擎对话不离开键盘。
06
权限审计audit.db
每一次文件写入与命令执行都落独立审计库，manual / auto / fine-grained 三种来源分开记账，失败不阻塞主流程。
07
托盘常驻menubar · darwin
菜单栏显示运行状态——运行中、等待授权一目了然；任务完成发系统通知，人不在屏幕前也不错过。

三步，一个本地循环。

没有云端排队，没有浏览器标签页——任务从下达到落地，全程跑在你自己的机器上。

下达任务prompt · natural language

用一句话交代要做什么，就像跟同事说话。要改哪个文件、跑什么命令、按什么标准收尾，一次说清。
