01

多会话管理

sessions · sidebar

左侧栏是全部会话的时间线：今天、本周、更早。会话可以置顶、归档、重命名，跨项目聚在一起，也能用 ⌘P 直接按名字跳转。

有 agent 停下来等授权的会话，侧栏里会亮「待确认」徽标——它的优先级高于一切状态，扫一眼就知道哪条线卡住需要你。

在哪：主窗口左侧栏；跳转在 ⌘P 面板。

02

回卷

rewind · truncate-from · event sourcing

会话底部有一条时间轴。把游标拖回任意一轮之前，消息树就在那个点截断，agent 从那里重新出发——不是清空上下文重来，是把走错的那一段切掉。

截断走事件溯源，同时下发 rewound 事件：被切掉的消息不会在断线重连重放时「复活」。这一步是 v0.4.x 里最花力气的一处工程，因为要让回放和现场保持一致。

在哪：会话窗口底部的时间轴，拖动即回卷；游标停在哪一轮，续跑就从哪一轮开始。

03

断点续传

sse resume · reconnect

事件流带序号，断线后从断点重放而不是整页重来；重连按指数退避自动进行。合盖休眠、切代理、弱网——回来时画面接着刚才的地方继续走。

这条链路同样覆盖中途断流的模型故障转移：备用端点接上后，会话状态不丢。

你会遇到它的时候
  1. 合上盖子再打开，会话自动续上，中间输出不缺页。
  2. 状态栏短暂显示重连中，无需手动刷新或重开会话。
04

worktree 隔离

git worktree · sandbox

新会话可以跑在当前仓库的 git worktree 副本里：agent 的所有改动落在隔离分支，合并回主工作区之前，先审、再合；不要就整枝丢弃。

试错和正式改动从此是两棵树——放心让它大改，主分支始终干净。

在哪：新建会话时勾选「worktree 隔离」，合并入口在会话的变更看板。

05

权限授权

hitl · permission cards

需要权限的动作——读文件之外的一切写操作与命令执行——agent 会停下来，弹出授权卡片：动什么、为什么、影响哪个路径，说清楚再问你。

三个按钮对应三种信任粒度：拒绝、允许一次、总是允许。选择会记入审计，事后可查可撤销。

人不在时任务卡在授权，侧栏亮「待确认」，托盘图标同步变化，系统通知提醒你回来拍板。

典型流程
  1. agent 请求执行 pnpm test，卡片说明命令与工作区。
  2. 选「允许一次」——本轮生效；选「总是允许」——同类命令后续静默放行。
  3. 每一次决定都落 audit.db，来源分开记账。
06

Diff 审阅

shiki highlight · changes panel

右侧看板实时呈现本轮触碰的文件与变更，Shiki 按语言按需加载语法高亮，明暗主题跟随系统。改动是逐行的，不是一段模糊的「已修改」。

确认与提交由你决定——机器不替你拍板。

在哪：会话右侧的 CHANGES 看板，随执行实时更新。

07

命令与搜索

cmd-K · cmd-P · cmd-Shift-F

三模式命令面板，键盘优先：⌘K 执行命令，⌘P 跳转会话，⌘⇧F 全文搜索全部历史——不只是标题，消息正文也在索引里。

和引擎对话不离开键盘，是这套工作台的基本假设。

快捷键速查
  1. ⌘K —— 命令面板：新建会话、切换模型、打开设置。
  2. ⌘P —— 会话跳转：按名字或项目过滤，回车即达。
  3. ⌘⇧F —— 全文搜索：跨全部会话找一句话。
08

上下文掌控

@-mention · context meter

输入框里 @ 可以直接引用文件与目录，agent 读的是你指的那一份，不靠猜。Composer 下方的占用条实时显示当前上下文用量，快满的时候你先知道。

每个会话可以单独选模型，长任务和轻问答不必共用一个配置。

在哪：底部 Composer 的 @ 引用与上下文占用条；模型选择在 Composer 右下角。

09

托盘常驻与通知

menubar · notifications

菜单栏图标常驻显示运行状态：运行中、等待授权一目了然。任务完成或需要你回来时发系统通知——人不在屏幕前，也不错过任何一条线。

在哪：macOS 菜单栏（屏幕右上角）；通知走系统通知中心。

10

本地数据与审计

sqlite · audit.db · local first

全部数据在你的磁盘上：会话落在单文件 SQLite（zmzai.db），每一次文件写入与命令执行单独记入 audit.db，manual / auto / fine-grained 三种来源分开记账，失败不阻塞主流程。

卸载应用不会自动删数据；备份就是把目录拷走。模型推理经过 relay，其余什么都不上云。

在哪：~/Library/Application Support/Lectern（Windows 为 %APPDATA%\Lectern）。

功能在持续补齐，推理档位贯通、跨会话记忆、自动更新都在路上——完整清单见 路线图；与同类形态的横向对比见 为什么是 Lectern。

看完功能，跑一个会话试试。
