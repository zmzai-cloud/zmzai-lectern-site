Why Lectern

不是又一个 agent 工具。

桌面工作台与终端 CLI、IDE 面板、Web 控制台不是同一物种——但人总想横向比一比。下面是按日常使用场景的对照，切换看差异。

终端里跑 agent 的那一类
场景Lectern 桌面工作台终端 CLI 常见形态
看变更变更摊在右侧看板：本轮触碰的文件 + Shiki 高亮 diff，与代码编辑区同屏对照滚动终端输出里的 patch 文本，靠眼睛比对
长会话几千条消息不卡：增量投影 O(1)，触顶自动分页加载历史上下文一滚出视野就找不回来，长会话靠人工 summary
断线续传SSE 序号续传 + 指数退避重连——弱网、休眠、代理切换不重来进程一断任务即丢，恢复靠重跑或 luck
审计每次写文件/执行命令落独立 audit.db，三类来源分开记账执行过的命令随时间滚出屏幕，事后无账可查
运行感知菜单栏常驻：运行中/等待授权一目了然，完成发系统通知想确认任务状态必须切回终端窗口盯着
寄生在编辑器里跑 agent 的那一类
场景Lectern 桌面工作台IDE 面板常见形态
独立性独立桌面应用，不绑定编辑器——不因换 IDE、升级插件而丢失工作流深度依赖宿主编辑器，离开它即失效
隔离worktree 会话隔离：新会话跑在隔离副本，合并前可审可弃直接在当前工作区动手，试错与正式改动混在一起
数据会话、审计、配置独立落盘可带走，跨项目聚合成一个时间线数据散在编辑器缓存里，换机器即失
多会话原生多会话管理：搜索、归档、置顶，互不干扰并行跑面板一次一个上下文，多任务靠开多个标签页将就
授权权限请求卡片化确认，卡住时侧边栏亮「待确认」，还有独立审计追溯授权提示与编辑窗口抢焦点，粒度粗且无事后追溯
云端网页里跑 agent 的那一类
场景Lectern 桌面工作台Web 控制台常见形态
数据主权数据不上云：会话与审计存本地磁盘，模型推理只过 relay 一层代码与上下文整体上云，隐私依赖平台承诺
连续性事件流驱动 + 断点续跑，刷新页面也不会丢中间态页面一关上下文归零，续接靠重新上传全部资料
延迟编辑、diff、搜索全本地渲染，操作零网络往返，弱网依旧可用每次击键与滚动都取决于网络与远端渲染
工作流对接本机文件系统与终端：改完即测、出包即验，agent 能碰真实产物跑在沙箱里，看得到代码看不到真实运行环境
离线断网时可继续编辑与审阅本地会话，联网后自动续上推理断网即停摆，什么都做不了
Local first

执行在本机，记录在你手里。

推理通过 relay 连接模型；会话、审计和运行进度则存放在你自己的磁盘上，随时可查看、可带走。

sessions
会话 · SQLite 单文件

所有会话落在 zmzai.db，旧版 JSONL 自动导入。历史和上下文都由你保管。

audit
审计 · 独立审计库

每一次文件写入与命令执行都记入 audit.db，manual / auto / fine-grained 三类来源分开记账。

resume
进度 · 离开即续

事件流带序号，断线后从断点重放，指数退避自动重连。休眠、弱网、代理切换都不会打断手上的活。
